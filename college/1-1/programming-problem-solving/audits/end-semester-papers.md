## Verified ambiguities and corrections

- January 2025 A(a) retains the printed separated equality signs and dash. Its answer explicitly interprets them as `==` and subtraction for the intended result 0; literal separated signs are invalid C.
- January 2024 A(c) retains `Void main()` and the printed code. The answer explains that the literal program is invalid standard C; with the entry point and header corrected, the array trace gives `12345`, without spaces. Each element is initialized before the next iteration reads it.
- The linear search saves the actual match index and stops there, rather than reporting the exhausted loop index. The minimum program initializes its accumulator and remembers the first minimum’s position. Pointer traversal includes input and resets the pointer before output.
- The Armstrong source tests cubes for three-digit numbers. The range program explicitly generalizes to the number of digits, including zero, using integer powers. Supported range is 0–9999.
- Source `strrev` is identified as a legacy extension. A portable reverse implementation demonstrates its intended behavior alongside the four standard library functions; no nonexistent standard `strrev` is claimed.
- Structure/union size statements include alignment/padding; register allocation is not guaranteed; reading uninitialized locals is not described as predictable “garbage output”.
- “White spaces” in the 2025 file question is interpreted explicitly: all whitespace, tabs and literal spaces are reported separately. A word is a maximal non-whitespace run.
