### Independent voltage source

Symbol: \(V_s\) / \(V\); \(V(t)\)

An independent voltage source maintains a voltage (fixed or varying with time) which is not affected by any other quantity.

### Ideal voltage source

A two-terminal element in which \(V_s\) is completely independent of current \(I_s\) through its terminals.

In V-I characteristics, at any time the value of \(V_s\) is constant with respect to current value \(I_s\).

### Practical voltage source

\[V=V_s-IR\]

Practical voltage source can be considered as series-combination of an ideal voltage source and resistance which is known as source resistance.

The reduction in voltage across the terminals with increasing load current is due to voltage drop in source resistance.

When the value of source resistance is 0, ideal condition is achieved in the voltage source. Hence source resistance/internal resistance of an ideal voltage source is 0.

### Ideal current source

An ideal current source is a two-terminal element in which current \(I_s\) is completely independent of voltage \(V_s\) across its terminals.

If we observe V-I characteristics of an ideal current source, at any time the value of current \(I_s\) is constant with respect to voltage across it.

[Redraw: ideal current source and constant-current I-V characteristic]

### Practical current source

\[I=I_s-\dfrac{V}{R}\]

The reduction in current delivered by source is due to current drawn by parallel source resistance.

Ideal condition: \(R=\infty\) (source resistance). Hence source resistance/internal resistance of an ideal current source is \(\infty\).
