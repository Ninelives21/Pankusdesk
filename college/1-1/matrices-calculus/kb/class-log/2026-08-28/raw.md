### Gauss Jordan method

This method is used to find inverse of non-singular matrix.

Procedure:

1. Let A be a non-singular matrix of order n. Write the given matrix with the identity matrix of order n.
2. Using only row transformations, reduce the A-side to the identity. The same row transformations applied to the identity side produce B, where B = A⁻¹.

### Example 1

\[
A=\begin{bmatrix}-2&1&3\\0&-1&1\\1&2&0\end{bmatrix}
\]
